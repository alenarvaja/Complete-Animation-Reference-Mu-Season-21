# MU Online – Player.bmd Animation Reference

A community reference for the player animations contained in MU Online's Season 21 client.

## Client Information

- **Client version:** 1.21.8.0
- **File:** Player.bmd
- **Total animations:** 410
- **Animation indices:** 0–409

## About

This mapping was originally created as part of the **LeMUria** project to facilitate the implementation of newer player animations in older MU Online clients.

Every animation was manually inspected and categorized based on its visual appearance. Some repetitive animation variants were grouped or not individually described.

The descriptions do not represent official Webzen animation names. Some class, weapon and skill associations are speculative.

## Purpose

This reference is intended to help MU Online developers with:

- Animation identification.
- Backporting animations to older clients.
- Custom class and skill development.
- Implementation of emotes and character interactions.
- BMD viewer and editor development.

## Contributions

Community contributions are welcome. If you recognize an unidentified animation, discover an incorrect description or know its official purpose, feel free to submit an issue or pull request.
